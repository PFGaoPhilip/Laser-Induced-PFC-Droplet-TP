# English lesson figures

Open `index.html` in this folder.
Move or forward the complete folder together.
The gallery uses local assets and includes day/night controls.

All 178 active lesson figures were redrawn through SCI-PPT.
Each figure includes editable native PowerPoint objects, SVG, and scene JSON.
The chapter decks contain 34, 36, 33, and 41 figures.
The appendix/studies deck contains 24 appendix diagrams and 10 study figures.

Each group includes scientific and actual-PowerPoint visual acceptance records.
Reviewers checked geometry, directions, signs, definitions, units, and assumptions.
Quantitative plots preserve the accepted data and source coordinates.
Curved vector paths use sampled Bézier coordinates during native conversion.
Model diagrams remain schematics and do not establish experimental validation.

`source-svg/` preserves the original equation diagrams.
`reference/` preserves the supplied screenshot.
These archival references retain their original languages.
Active lesson figures and gallery figures use English labels.

The lesson embeds SVGs in both language modes.
PowerPoint changes require corresponding SVG regeneration before re-embedding.
Source scene files retain the geometry and live text for reproduction.
