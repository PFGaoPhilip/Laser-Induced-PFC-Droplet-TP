# Teaching preferences
# 教学偏好

Use the supplied before/after comparison to keep a single project route. Reuse the earlier course's scientific arrangement and visual clarity, without duplicating its parallel reference libraries.

依据提供的重构前后对比保持单一项目路线。沿用此前课程的科学编排及清晰视觉设计，不重复其并列参考资料库。

Keep English and Chinese adjacent; the same technical concept has the same color in a paragraph pair, and different concepts in that pair use different colors. Default dark mode with a day/night toggle.

英语与中文紧邻；同一概念在双语段落对中使用相同颜色，不同概念使用不同颜色。默认深色模式并提供日／夜切换。

Use Newton dots for radius time derivatives. Show every displayed formula with prior symbol definitions and its corresponding physical variable figure. Reference answers quote original formulas before explanatory reasoning.

半径时间导数使用牛顿点号。每个独立公式前定义符号，公式后附相应物理变量图。参考答案先引用原公式，再说明推理。

Every equation title uses the inline layout “English / 中文,” matching the physical-variable-map labels. Both languages share one heading and may wrap naturally on narrow screens. An untranslated title must stop the build.

每个公式标题采用与物理变量图标签一致的同行排版“English / 中文”。两种语言属于同一个标题，可在窄屏上自然折行。缺少中文标题时必须中止构建。

Exactly three defense questions per chapter and in Appendix A. Correct own-word explanations can demonstrate mastery; worked calculations are teaching examples, not an extra homework requirement. Every glossary row defines one variable with its own meaning, units and role.

每章及附录 A 各有恰好三个答辩问题。正确的自主解释可展示掌握；已解计算是教学例题，不是额外作业要求。每个符号表行仅定义一个变量，并单独注明意义、单位及作用。
